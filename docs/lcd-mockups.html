CRSF Channels

Default landing screen after boot. The layout uses a 4x4 grid so all 16 normalized channels are visible at once without scrolling.

Main content `Ail`, `Elv`, `Thr`, `Roll`, `Aux1...Aux12`, plus RX live state and telemetry TX summary.
Mockup choice Each channel uses a compact number and bar so the user sees exact value and stick position together.
Button model `Btn B` opens telemetry overview, `Btn C` jumps to link statistics, `Btn A` stays local.

Link Statistics

Diagnostics screen for radio quality. The mockup keeps all ten required uplink/downlink fields on a single page while leaving room for update age.

Main content RSSI, LQ, SNR, active antenna, RF mode, TX power, and freshness of statistics.
Mockup choice Two-column instrumentation cards reduce eye travel and preserve numeric readability.
Button model `Btn A` returns to channels, `Btn B` opens overview, `Btn C` can switch density or pages if needed.

Telemetry Overview

Central hub for telemetry state and GPS source selection. The active source is visible in the header and repeated as selector chips to make switching obvious.

Main content GPS, Attitude, Barometric Altitude, Battery, Flight Mode, and CRSF telemetry send state.
Mockup choice Six dense cards keep the summary complete while preserving one-button entry into the selected source screen.
Button model `Btn C` rotates source `Manual -> External GPS -> Simulator`, `Btn B` enters the active source screen.

Manual Telemetry

Editing-focused screen for manually entered telemetry. The mockup shows the selected field and the current editor state at the same time.

Main content Editable fields for GPS, Attitude, Barometric Altitude, Battery, and `Flight Mode` with fixed mode list.
Mockup choice List on the left, editor on the right. This keeps button semantics predictable in both view and edit states.
Button model In edit mode: `Btn A` decrease/cancel, `Btn B` confirm, `Btn C` increase/select next value.

Simulation Parameters

Control surface for GPS simulation, profile selection, and SDCard-backed JSON save/load operations. The active profile and last storage status remain visible.

Main content Start position, altitude, speed, course, update interval, satellites, fix flag, commands, and JSON profile path.
Mockup choice Left side holds numeric parameters, right side keeps commands and SDCard status separated from value editing.
Button model `Btn B` edits the selected parameter or executes `Start/Pause/Stop/Reset/Save JSON/Load JSON`.

GPS Status

Diagnostic screen for the external GPS receiver on software UART. The mockup emphasizes connection state, parsed NMEA flow, and the most recent position data.

Main content Connection state, stream presence, protocol, coordinates, speed, course, altitude, satellites, fix validity, last update.
Mockup choice Two panels split receiver health from decoded fields, which makes serial and parser failures easier to spot quickly.
Button model `Btn B` refreshes or changes detail, `Btn C` toggles compact versus extended diagnostics.
Use case Review screen density, information hierarchy, and per-screen button behavior before firmware implementation.
Scope Static HTML mockup only. No firmware assets or generated graphics.
